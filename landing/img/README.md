# Скриншоты для лендинга

Эта папка должна лежать **рядом с `index.html`**, то есть итоговая структура на хостинге такая:

```
/                      (корень сайта bulak.tlbk.kg)
├── index.html         ← файл лендинга из этой папки landing/
└── img/
    ├── phone-1.png
    ├── phone-2.png
    ├── phone-3.png
    ├── phone-4.png
    ├── phone-5.png
    ├── phone-6.png
    └── og.png         (картинка для соцсетей, 1200 × 630)
```

Важно: `index.html` ссылается на картинки **относительными** путями (`img/phone-1.png`).
Если положить файлы в другую подпапку или переименовать — картинки не появятся.

## Что положить в папку

| Файл | Где используется | Что должно быть на кадре |
|---|---|---|
| `phone-1.png` | Первый экран (крупно) и первая карточка галереи | Главная: приветствие, блок «Продолжить», плитки коллекций и карточки видео с превью |
| `phone-2.png` | Галерея, «Коллекция» | Открытая коллекция-папка с эмодзи и цветным заголовком, внутри — карточки видео |
| `phone-3.png` | Галерея, «Плеер» | Плеер во весь экран: крупные кнопки «назад 10 с», «играть/пауза», «вперёд 10 с» и видимый «замочек» |
| `phone-4.png` | Галерея, «Лимит времени» | Экран «На сегодня всё» после окончания дневного лимита |
| `phone-5.png` | Галерея, «Загрузки» | Экран загрузок: список скачанных видео и сколько места занято на телефоне |
| `phone-6.png` | Галерея, «Для родителя» | Родительский раздел: добавление ссылок и/или ввод PIN-кода |
| `og.png` | Превью ссылки в соцсетях (`og:image`, `twitter:image`) | Логотип «Булак» и один-два экрана приложения, 1200 × 630, без мелкого текста |

## Рекомендации по файлам

- **Размер:** 1080 × 1920 (вертикальный, 9:16) — стандарт для Google Play. Другие вертикальные пропорции тоже подойдут: картинка обрезается по `object-fit: cover` с выравниванием по верху, поэтому важное не должно быть у самого низа кадра.
- **Вес:** до ~400 КБ на файл, формат PNG или JPG (jpeg-качество 85–90 достаточно). Итого страница не должна тяжелеть больше, чем на ~2–3 МБ.
- **Что убрать со скриншота:** системные полосы Android (статус-бар и полосу навигации) — приложение и так рисуется внутри «рамки телефона» на странице. Уведомления, имена Wi-Fi, заряд батареи, курсор мыши не нужны.
- **Изображение обрезается по краям:** сверху и снизу контейнер чуть подрезает кадр, поэтому не размещайте важные кнопки вплотную к верхней и нижней кромке.
- **Тексты:** кадры лучше делать на русской локали приложения — лендинг русскоязычный.
- **`alt` уже написан** в `index.html` под каждый кадр. Если меняете содержимое кадра — поправьте и `alt`, чтобы он описывал то, что реально видно.

## Пока картинок нет

Это нормально: страница не сломается. У контейнера каждого «телефона» есть светлый зелёный фон и скругление, а вместо картинки браузер покажет текст `alt`. Как только файлы появятся в `img/`, они встанут на свои места без правок кода.

## Как проверить локально

1. Откройте `landing/index.html` двойным щелчком в браузере — вся вёрстка и скриншоты (если они уже в `img/`) работают из файла, без сервера.
2. Если картинки не отображаются при открытии через `file://` — запустите в папке `landing/` любой статический сервер, например `python -m http.server 8080`, и откройте <http://localhost:8080/>.
3. Проверьте 320 и 360 px в инструментах разработчика (F12 → режим устройства): горизонтальной прокрутки быть не должно.
