# Скриншоты для лендинга

Эта папка должна лежать **рядом с `index.html`**, то есть итоговая структура на хостинге такая:

```
/                                      (корень сайта bulak.edu.kg)
├── index.html                         ← кыргызская версия (главная страница)
├── index.ru.html                      ← русская версия
└── img/
    ├── ky/
    │   ├── phone-1.png
    │   ├── phone-2.png
    │   ├── phone-3.png
    │   ├── phone-4.png
    │   ├── phone-5.png
    │   └── phone-6.png                (кадры для кыргызской страницы)
    ├── phone-1.png
    ├── phone-2.png
    ├── phone-3.png
    ├── phone-4.png
    ├── phone-5.png
    ├── phone-6.png                    (кадры для русской страницы)
    └── og.png                         (картинка для соцсетей, 1200 × 630)
```

Важно: страницы ссылаются на картинки **относительными** путями.

| Страница | Какие кадры берёт |
|---|---|
| `index.html` — кыргызская (главная) | `img/ky/phone-1.png` … `img/ky/phone-6.png` |
| `index.ru.html` — русская | `img/phone-1.png` … `img/phone-6.png` |
| обе страницы, превью в соцсетях | `img/og.png` (общая картинка) |

Если положить файлы в другую подпапку или переименовать — картинки не появятся.

## Папка `ky/`

Кыргызская страница (`index.html`) берёт все шесть кадров из `ky/`, поэтому кадры в двух папках
можно обновлять независимо: русские — в `img/`, кыргызские — в `img/ky/`.

**Часть кадров в `ky/` уже снята на кыргызском интерфейсе**, остальные пока копии русских:
страница работает сразу и ничего не ломается.

| Файл | Состояние |
|---|---|
| `ky/phone-1.png` (главная) | снят на кыргызском |
| `ky/phone-2.png` (коллекции) | снят на кыргызском |
| `ky/phone-3.png` (плеер) | пока копия русского кадра |
| `ky/phone-4.png` (лимит времени) | пока копия русского кадра |
| `ky/phone-5.png` (загрузки) | пока копия русского кадра |
| `ky/phone-6.png` (родительский раздел) | пока копия русского кадра |

Когда появятся оставшиеся кадры с кыргызским интерфейсом, просто замените файлы в `ky/`
с теми же именами — править код страницы не нужно. Подписи и `alt` в кыргызской версии
уже описывают те же экраны, что и в русской.

## Рекомендации по файлам

- **Размер:** 1080 × 2340 (вертикальный, 9:19.5 — как у типичного Android-телефона). Именно это соотношение у рамки телефона на странице, поэтому такой кадр встаёт без обрезки. Другие вертикальные пропорции тоже подойдут: картинка обрезается по `object-fit: cover` с выравниванием по верху, поэтому важное не должно быть у самого низа кадра.
- **Вес:** до ~400 КБ на файл, формат PNG или JPG (jpeg-качество 85–90 достаточно). Сейчас каждая папка — около 1,4 МБ.
- **Что убрать со скриншота:** системные полосы Android (статус-бар и полосу навигации) — приложение и так рисуется внутри «рамки телефона» на странице. Уведомления, имена Wi-Fi, заряд батареи, курсор мыши не нужны.
- **Язык интерфейса на кадре:** в `img/` — русская локаль (русская страница русскоязычная), в `img/ky/` — кыргызская (кадры для главной страницы; пока там копии русских).
- **`alt` уже написан** в обоих файлах под каждый кадр. Если меняете содержимое кадра — поправьте и `alt`, чтобы он описывал то, что реально видно.

> **Важно про сборку.** Кадры сняты с **личной** сборки приложения — той, где видео скачивается на телефон. Экраны «Готовим видео» и «Загрузки» в сборке для Google Play и App Store отсутствуют: там скачивание отключено и видео играет потоком. Если будете переснимать, снимайте личную сборку — иначе страница расскажет про офлайн-режим, которого в магазинной версии нет.

## Если картинки не загрузились

Страница не сломается: у контейнера каждого «телефона» есть светлый зелёный фон и скругление, а вместо картинки браузер покажет текст `alt`. Как только файлы появятся в `img/` или `img/ky/`, они встанут на свои места без правок кода.

## Как проверить локально

1. Откройте `landing/index.html` (кыргызская, главная) или `landing/index.ru.html` (русская) двойным щелчком в браузере — вся вёрстка и скриншоты (если они уже в папках) работают из файла, без сервера.
2. Переключатель языка — в шапке справа: «Кыргызча» ведёт на `index.html`, «Русский» — на `index.ru.html`. На ширине меньше 400 px виден только текущий язык, иначе переключатель не помещается рядом с кнопкой скачивания.
3. Если картинки не отображаются при открытии через `file://` — запустите в папке `landing/` любой статический сервер, например `python -m http.server 8080`, и откройте <http://localhost:8080/>.
4. Проверьте 320 и 360 px в инструментах разработчика (F12 → режим устройства): горизонтальной прокрутки быть не должно.
