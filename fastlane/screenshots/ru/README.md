# Скриншоты для App Store — локаль `ru`

В эту папку складываются готовые скриншоты для русской локализации App Store.
Файлы отсюда можно загрузить вручную через **App Store Connect → Screenshots**
или автоматически через `fastlane deliver` (`deliver` берёт их из `fastlane/screenshots/<locale>/`).

## Обязательные размеры

Актуальный список обязательных размеров Apple меняет, поэтому **перед загрузкой сверьтесь
с App Store Connect → Screenshots**.

| Устройство | Размер | Обязательность |
|---|---|---|
| iPhone 6.9" (iPhone 16 Pro Max и аналоги) | **1320 × 2868** | Обязательно |
| iPhone 6.7" (iPhone 15 Pro Max и аналоги) | **1290 × 2796** | Часто обязательно |
| iPhone 6.5" (iPhone 11 Pro Max и аналоги) | 1242 × 2688 или 1284 × 2778 | Опционально, если покрыт 6.9" |
| iPhone 5.5" (iPhone 8 Plus) | 1242 × 2208 | Опционально |
| iPad 13" | **2064 × 2752** | Обязательно, если приложение поддерживает iPad |
| iPad 12.9" (поколения 3–6) | 2048 × 2732 | Часто обязательно |
| iPad 11" | 1668 × 2388 | Опционально |

**Практический вывод:** для iPhone готовьте один набор **1320 × 2868** (6.9") и один
**1290 × 2796** (6.7"). Для iPad — **2064 × 2752**.

## Общие требования к файлам

| Параметр | Значение |
|---|---|
| Формат | PNG (предпочтительно) или JPEG |
| Цветовое пространство | sRGB |
| Ориентация | Портрет для iPhone; портрет и ландшафт допустимы для iPad |
| Размер файла | до 8 МБ на скриншот |
| Количество | от 1 до 10 на размер экрана |
| Рамки устройств | Не добавлять |
