# Иконка для магазина приложений Android (en-US)

| Параметр | Значение |
|---|---|
| Файл | `icon.png` |
| Размер | **512 × 512 px** |
| Формат | PNG, **без альфа-канала** |
| Размер файла | до 1 МБ |

## Что на ней

Зелёный скруглённый квадрат с белым скруглённым треугольником воспроизведения —
тот же знак, что и иконка приложения на телефоне. Палитра `#4ADE80` → `#22C55E` → `#16A34A`.

## Как пересобрать

```bash
python tools/icon/build_assets.py
```

Скрипт рисует знак кодом и раскладывает готовые файлы сразу во все локали.
Отдельно рисовать в графическом редакторе ничего не нужно.

Источник: документация проекта в `docs/store/`.
