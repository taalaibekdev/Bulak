# 10" tablet screenshots — Google Play (en-US)

Place **up to 8** files here: `1.png`, `2.png`, … (order = display order in the store).

| Parameter | Value |
|---|---|
| Size | **1920 × 1200 px** (landscape) |
| Alternative from the project docs | **1600 × 2560** (portrait) or **2560 × 1600** (landscape) — the 10" tablet recommendation in `docs/store/google-play/store-assets.md` |
| Accepted size | 320 to 3840 px per side; aspect ratio from 16:9 to 9:16 |
| Format | PNG or JPEG |
| File size | up to 8 MB each |
| Count | 4–6 preferred |
| File names | `1.png` … `8.png` |

1920 × 1200 is a valid landscape size for a 10" tablet and is accepted by Play;
if you shoot portrait, use 1600 × 2560.

## What to capture

The home grid (a wide screen shows more videos at once), collections, the player and parent mode.
Captions are the same as for the phone frames (frames 1, 2, 3, 5).

## Important

Tablet screenshots must come from a real tablet or an emulator running at tablet resolution.
Play may reject a stretched phone screenshot: the interface has to look correct.

Source: `docs/store/google-play/store-assets.md`, section 6.
