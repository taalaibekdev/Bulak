# Скриншоты 10" планшета — Google Play (ru-RU)

Положите сюда **до 8** файлов: `1.png`, `2.png`, … (порядок = порядок показа в сторе).

| Параметр | Значение |
|---|---|
| Размер | **1920 × 1200 px** (ландшафт) |
| Альтернатива из документации проекта | **1600 × 2560** (портрет) или **2560 × 1600** (ландшафт) — рекомендация `docs/store/google-play/store-assets.md` для 10" планшета |
| Допустимый размер | от 320 до 3840 px по каждой стороне; соотношение сторон от 16:9 до 9:16 |
| Формат | PNG или JPEG |
| Размер файла | до 8 МБ каждый |
| Количество | желательно 4–6 |
| Имена файлов | `1.png` … `8.png` |

1920 × 1200 — корректный ландшафтный размер для 10" планшета и принимается Play;
если снимаете в портрете, используйте 1600 × 2560.

## Что снимать

Главная-сетка (на широком экране видно больше видео одновременно), коллекции, плеер,
родительский режим. Подписи — те же, что для телефона (кадры 1, 2, 3, 5).

## Важно

Планшетные скриншоты снимаются на реальном планшете или в эмуляторе с планшетным разрешением.
Растянутый телефонный скриншот Play может отклонить: интерфейс должен выглядеть корректно.

Источник: `docs/store/google-play/store-assets.md`, раздел 6.
