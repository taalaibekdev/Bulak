# Feature graphic — Google Play (ru-RU)

Положите сюда **один** файл: `featureGraphic.png` (или `featureGraphic.jpg`)

| Параметр | Значение |
|---|---|
| Размер | **1024 × 500 px** |
| Формат | PNG или JPEG, **без альфа-канала** |
| Размер файла | до 15 МБ |
| Имя файла | `featureGraphic.png` / `featureGraphic.jpg` |

## Композиция

- Свободные поля: не размещайте критичные элементы ближе **40 px** к краям и в центре.
- **Центр:** оставьте свободной горизонтальную полосу высотой около **120 px** по центру —
  Play накладывает туда кнопку воспроизведения промо-видео.
- **Слева (~45 % ширины):** три уменьшающиеся карточки видео «в перспективе», настоящие превью из приложения.
- **Справа (~30 %):** крупный силуэт или мягкая иллюстрация ребёнка в наушниках с планшетом
  (без реальных фотографий детей).
- **Фон:** фирменный градиент `#2AD1FF` → `#2A6BFF` → `#6C4BFF` либо тёмная основа `#0E1B3A`
  с тем же градиентом в акцентах.

## Подпись (ru-RU)

```
Видео, которые вы отобрали сами
```

Слева вверху, шрифт **Nunito ExtraBold**, не менее **44 px**, достаточный контраст к фону.
Слово YouTube в подписи использовать нельзя.
