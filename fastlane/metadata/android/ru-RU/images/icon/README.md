# Иконка приложения — Google Play (ru-RU)

Положите сюда **один** файл: `icon.png`

| Параметр | Значение |
|---|---|
| Размер | **512 × 512 px** (ровно, без масштабирования стороною) |
| Формат | 32-битный **PNG** |
| Альфа-канал | **Запрещён** — иконка должна быть полностью непрозрачной |
| Размер файла | до 1 МБ |
| Безопасная зона | 24 px со всех сторон: ничего важного не должно попадать в эту рамку |
| Имя файла | `icon.png` (именно так, fastlane supply загружает его автоматически) |

## Что изобразить

Концепция «родник» (`concept_b_spring`) — рекомендуется в `docs/store/google-play/store-assets.md`:
округлый камень или чаша, из которой поднимается капля, внутри — треугольник воспроизведения.
Альтернативы и эскизы: `assets/icon/concepts/`.

## Чего избегать

- красный скруглённый прямоугольник с белым треугольником (логотип YouTube);
- слово «YouTube» и любые чужие товарные знаки;
- мелкие детали, которые исчезнут при показе в 48 px;
- фотореалистичные изображения детей;
- текст на иконке — в Play иконка показывается мелко, надписи не читаются.

> Это **отдельный** файл 512 × 512 без альфа-канала. Он не совпадает с `assets/icon/app_icon.png`,
> который попадает внутрь приложения.

Источник: `docs/store/google-play/store-assets.md`, раздел 3.
