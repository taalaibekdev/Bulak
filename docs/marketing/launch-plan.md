# План запуска приложения «Булак»

Документ описывает подготовку к запуску, действия в день релиза, план на первые 30 дней, площадки для продвижения и готовые шаблоны постов.

**Приложение:** «Булак» (Bulak), `kg.tlbk.bulak`. Бесплатное, без покупок и подписок. Рынки первого этапа: Кыргызстан, Россия, Казахстан. Языки: русский (основной), английский.

---

## 1. Цели запуска

| Цель | Метрика | Горизонт |
|---|---|---|
| Проверить, что продукт работает на реальных устройствах | 0 критических сбоев, 0 отзывов о крашах | Первая неделя |
| Получить первую обратную связь от родителей | 15–30 содержательных отзывов или сообщений в поддержку | Первый месяц |
| Достичь базового рейтинга | 4,5+ при минимум 20 оценках | Первый месяц |
| Понять, какой аргумент работает | Вывод по первому Store Listing Experiment | Первый месяц |
| Подготовить базу для версии 1.1 | Список из 10+ улучшений от пользователей | Первый месяц |

**Чего не делаем на запуске:** не покупаем рекламу, не покупаем отзывы, не рассылаем спам в сообщества, не обещаем функций, которых нет.

3. Не спорить с критикой публично; уводить технические вопросы в личные сообщения или в поддержку.
4. Следить за отчётами о сбоях каждые 2–3 часа.

| Канал | Как заходить |

- бесплатное использование, без покупок;

- родитель сам формирует список видео;
- готовую инструкцию для родителей на одну страницу;
- готовые подписи и логотип для упоминания.

```
Мы устали от того, что детский просмотр превращается в бесконечную ленту.

Как это работает:
1. Вы находите мультик или песенку на YouTube и копируете ссылку.

• Крупные кнопки в плеере — ребёнок разберётся сам
• Родительский замок: выйти из плеера можно только по PIN

Чего нет: поиска, рекомендаций, ленты, Shorts, комментариев, подписок.
Данные не собираются — всё хранится на вашем устройстве.

Бесплатно, без покупок и подписок.
```

## 7. Метрики запуска

| Метрика | Как считать | Целевое значение первого месяца |
|---|---|---|
| Установки | Play Console, App Store Connect | 300–1000 (зависит от охвата сообществ) |
| Конверсия страницы приложения | Установки / посетители страницы | 20–35 % |
| Средний рейтинг | Оба стора | 4,5+ |
| Количество оценок | Оба стора | 20+ |
| Отзывы с ответом | Вручную | 100 % |
| Обращения в поддержку | Почта | 15–30 |
| Доля критических сбоев | Android vitals, App Store Connect | 0 |
| Повторные установки / упоминания | Наблюдение | Рост к концу месяца |

**Критерии успеха:** приложение стабильно, есть первые отзывы и понятно, что улучшать в 1.1.

**Критерии проблем:** установок меньше 100 за месяц, рейтинг ниже 4,0, есть повторяющиеся жалобы на неработающие видео.

**Что делать, если установок мало:**

1. Проверить, находится ли приложение по поиску по слову «Булак» и по запросу «видео для детей».
2. Проверить конверсию страницы: если посетители есть, а установок нет — проблема в скриншотах или описании.
3. Проверить первый скриншот: понятно ли за 3 секунды, что это и для кого.
4. Усилить работу в сообществах: не разовыми постами, а участием в обсуждениях.
5. Договориться о честном обзоре с 2–3 блогерами-родителями.
6. Проверить локальные площадки Кыргызстана: возможно, там аудитория отзывчивее.
7. Не покупать рекламу до того, как конверсия страницы доведена до 20 %+.

## 8. План на случай проблем

| Проблема | Действие |
|---|---|
| Критический сбой в релизе | Остановить поэтапный выпуск; выпустить hotfix с новым номером сборки; при необходимости снять с продажи в App Store |
| Жалобы на неработающие видео | Проверить, не изменился ли механизм получения прямого потока; убедиться, что резервный режим с официальным плеером YouTube работает; объяснить пользователям причину |
| Жалоба правообладателя | Действовать по процедуре из `docs/legal/youtube-compliance.md`, раздел 8 |
| Отклонение в сторе | Исправить причину по `docs/publishing/release-checklist.md`, раздел 13 |
| Негативная волна отзывов | Ответить на каждый отзыв по существу, исправить проблему, не спорить публично |
| Приложение не находят в поиске | Проверить индексацию по названию, усилить ключевые слова в описании, дать прямые ссылки на сторы во всех постах |
