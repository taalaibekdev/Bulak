# Android дүкөнү — «Булак» колдонмосунун листинги (KY)

Android дүкөнүнүн консолу үчүн даяр талаалар. Бул листингдин тили — **кыргызча (ky-KG)**; негизги листинг `listing.ru.md` (ru-RU) болуп калат.

Талааларга чаптоодон мурун чектөөлөрдү текшериңиз: төмөнкү тексттердин баары Play лимиттерине батат.

---

## 1. Колдонмонун аталышы

**Лимит: 30 белги.** Негизги вариант:

```
Булак — балдар үчүн видео
```

**Узундугу: 25 белги.**

Альтернативалар (эгер аталыш бош эмес болуп чыкса):

| Вариант | Текст | Узундугу |
|---|---|---|
| A (негизги) | `Булак — балдар үчүн видео` | 25 |
| B | `Булак — коопсуз видео` | 21 |
| C | `Булак: балдар видеосу` | 21 |
| D | `Булак — балдар ойноткучу` | 24 |

> Аталышта атайылап башкалардын товардык белгилери жана башка сервистердин аталыштары жок: аларды колдонмонун брендинин бөлүгү катары колдонууга болбойт.

## 2. Кыскача баяндама

```
Өзүңүз тандаган видео. Издөө, тасма жана сунуштар жок.
```

**Узундугу: 54 белги.**

Альтернативалар:

| Вариант | Текст | Узундугу |
|---|---|---|
| A (негизги) | `Өзүңүз тандаган видео. Издөө, тасма жана сунуштар жок.` | 54 |
| B | `Балдар ойноткучу: видеону ата-эне тандайт. Издөө жок.` | 53 |
| C | `Балдарга тынч видео: ата-эне тандаган нерсе гана.` | 49 |

## 3. Толук баяндама

**Лимит: 4000 белги.** Төмөнкү текстти бүт бойдон, абзацтардын ортосундагы бош саптарды кошо чаптаңыз.

```
🎬 «Булак» — балдар үчүн тынч видео

«Булак» — видеону өзүңүз, ата-эне, тандай турган ойноткуч. Эч кандай алгоритм жана сунуш жок: өзүңүз кошкон мультфильмдер, ырлар жана сабактар гана.

Кантип иштейт:
1. Видео кызматынан ылайыктуу видеону таап, шилтемесин көчүрөсүз.
2. Ата-энелик PIN киргизип, шилтемени колдонмого сактайсыз.
3. Бала «Булакты» ачып, чоң кооз карточкаларды көрөт — сиздин видеолоруңуз гана.

👶 Бала эмне көрөт
• Чоң превьюлар жана түшүнүктүү карточкалар
• Чоң, ыңгайлуу баскычтары бар толук экрандуу ойноткуч
• Эмодзи жана түс менен белгиленген топтомдор: «Мультфильмдер», «Окуу», «Музыка»
• Сүйүктүүлөр — сүйгөн видеосунда жүрөкчө
• Көрүү тарыхы
• Күнүмдүк чек бүткөндө чыккан жылуу «Бүгүнкүсү бүттү» экраны
• Ата-энелик кулпу: ойноткучтан PIN-код менен гана чыгууга болот

🔒 PIN-код менен гана ата-энеге жеткиликтүү
• Шилтеме аркылуу видео кошуу
• Видеонун атын өзгөртүү
• Видеону өчүрүү
• Видеолорду топтомдорго бөлүштүрүү
• Күнүмдүк экран убактысынын чегин коюу
• PIN-кодду алмаштыруу
• Бардык маалыматты тазалоо

🚫 Колдонмодо эмне жок
• Издөө
• Сунуштар жана түгөнгүс тасма
• Shorts
• Комментарийлер
• Жазылуулар жана каналдар
• Чаттар жана башка адамдар менен баарлашуу
• Биздин жарнактарыбыз
• Каттоо жана аккаунттар
• Видео жүктөө жана интернетсиз көрүү — бул курулушта алар жок

🔐 Маалыматыңыз өзүңүздө калат
Колдонмо жеке маалыматтарды жыйнабайт. Шилтемелердин тизмеси, аттар, топтомдор, сүйүктүүлөр, көрүү тарыхы жана жөндөөлөр түзмөгүңүздө гана сакталат. Аккаунт жок, иштеп чыгуучунун серверлери жок, аналитика жок, трекерлер жок, жарнак SDK жок. PIN-код кайтарылгыс хэш түрүндө сакталат. Каалаган убакта «Баарын тазалоо» баскычын басып, маалыматты толук өчүрө аласыз.

📶 Интернет керек
Бул курулушта видео жана превью видео кызматынын серверлеринен жүктөлөт, ошондуктан интернет жок көрүү мүмкүн эмес: видео жүктөө жана интернетсиз режим бул жерде өчүрүлгөн, ал эми видео ар дайым агым аркылуу ойнотулат.

👨‍👩‍👧 Ата-энелерге
Колдонмого кайсы видеолор кошулганы үчүн жоопкерчиликти ата-эне тартат. Колдонмо видеолордун мазмунун текшербейт, баалабайт жана чыпкалабайт — сиз тандаган нерсени гана көрсөтөт. Балаңызга аларды ачып берүүнүн алдында видеолорду өзүңүз көрүп чыгыңыз.

💛 Кимге ылайыктуу
Болжол менен 3 жаштан 10 жашка чейинки балдарга жана кокустан чыккан видеолорсуз тынч көрүүнү каалаган ата-энелерге.

ℹ️ Маанилүү
«Булак» колдонмосу эч кандай видео кызматы менен байланыштуу эмес, анын ээси тарабынан каржыланбайт жана жактырылган эмес. Бул курулушта колдонмо видеолорду жүктөбөйт жана алардын көчүрмөлөрүн сактабайт: жүктөө куруу этабында өчүрүлгөн, ал эми ойнотуу ар дайым видео кызматынын расмий механизмдери аркылуу агым менен аткарылат. Биз өз жарнактарыбызды көрсөтпөйбүз жана колдонмого жарнак SDKларын жайгаштырбайбыз; бирок камдык ички ойноткучта жарнакты видео кызматы өзү көрсөтүшү мүмкүн.

Акысыз. Ички сатып алуулар жана жазылуулар жок.

Колдоо: info@mits.kg
Сайт: https://mits.kg/bulak
Купуялык политикасы: https://mits.kg/privacy-policies/bulak.html
```

**Чыныгы узундугу: 3 005 белги** — 4000 лимитине оңой батат. Android дүкөнүнүн консолунун эсептегичи бир аз башка сан көрсөтүшү мүмкүн: эмодзилер бир нече коддук бирдик катары эсептелет. Жаңы блокторду кошсоңуз, Android дүкөнүнүн консолундагы калдыкты көзөмөлдөңүз.

## 4. Тегдер жана ачкыч сөздөр

Play'де ачкыч сөздөр үчүн өзүнчө талаа жок — издөө аталыш, кыскача жана толук баяндама боюнча иштейт. Ошондуктан ачкыч суроолорду **тексттердин ичине токуу** керек. Төмөндө иштеген суроолордун тизмеси жана ар бири кайда колдонулганы көрсөтүлгөн.

| Ачкыч суроо | Кайда эске алынган |
|---|---|
| балдар үчүн видео | аталышы, толук баяндама |
| балдар видеосу | аталышы, толук баяндама |
| балдар ойноткучу | аталышы (D варианты), ASO документ |
| балдар үчүн коопсуз видео | кыскача баяндама (B варианты), ASO |
| сунушсуз видео | кыскача баяндама, толук баяндама |
| издөөсүз | кыскача баяндама, толук баяндама |
| видео ата-эне көзөмөлү | толук баяндама, ASO |
| экран убактысынын чеги | толук баяндама |
| балдар үчүн мультфильмдер | толук баяндама (топтомдор) |
| балдар үчүн ырлар | толук баяндама |
| балдар үчүн сабактар, окуу | толук баяндама (топтомдор) |
| балага ойноткуч | ASO, толук баяндама |
| бөбөктөр үчүн видео | ASO |

**Android дүкөнүнүн консолунун «Тегдер» бөлүмү үчүн тегдер** (дүкөндүн тизмесинен тандалат, 5ке чейин):

1. Education
2. Video players & editors
3. Parenting
4. Entertainment

> Тегдерге колдонмонун функцияларында жок формулировкаларды кошпоңуз: Play баяндама менен функциялардын шайкештигин текшерет.

## 7. Жарнак жана сатып алуулар

Бул жооптор Data safety формасы менен жана колдонмонун иш жүзүндөгү жүрүм-туруму менен **так дал келиши керек**.

| Суроо | Жообу |
|---|---|
| Колдонмодо жарнак барбы? | **Жок** — колдонмодо жарнак SDK жок жана ал өз жарнагын көрсөтпөйт |
| Үчүнчү тараптын жарнагы көрсөтүлөбү? | **Ооба, чектелген түрдө**: камдык ички ойноткучта жарнакты видео кызматы өзү көрсөтүшү мүмкүн. Бул видео кызматтын ээсинин жарнагы, иштеп чыгуучунуку эмес; ал балага атайылап багытталбайт жана колдонмо тарабынан башкарылбайт |
| Колдонмодо ички сатып алуулар барбы? | **Жок** |
| Колдонмодо жазылуулар барбы? | **Жок** |
| Акы төлөнүүчү мазмун барбы? | **Жок** |
| Тышкы шилтемелер барбы? | **Ооба**, алардын баары ата-энелик PIN-код менен жабылган: шилтеме аркылуу видео кошуу жана камдык ойноткучта видео кызматынын баракчасын ачуу |
| Колдонуучулардын ортосунда маалымат алмашуу барбы? | **Жок** |

**«Жарнак барбы» деген суроого сунушталган формулировка**, эгер Android дүкөнүнүн консолу эркин комментарий берсе:

> Биз өз жарнактарыбызды көрсөтпөйбүз жана колдонмого жарнак SDKларын жайгаштырбайбыз. Камдык ички ойноткучта жарнакты видео кызматы өзү көрсөтүшү мүмкүн.
