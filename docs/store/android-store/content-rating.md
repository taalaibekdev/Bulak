# магазин приложений Android — возрастной рейтинг и анкеты (IARC, Designed for Families)

Документ содержит готовые ответы на анкету **IARC** в консоль магазина, ожидаемые рейтинги для целевых рынков и ответы на раздел **«Designed for Families / Приложения для детей»**.

Приложение: «Булак» (Bulak), `kg.tlbk.bulak`, версия 1.0.0.
Аудитория: дети 3–10 лет; покупатель и настройщик — родитель.

---

## 1. Как заполняется анкета IARC в консоль магазина

Путь: **App content → Content rating → Start questionnaire**.

| Шаг | Что выбрать |
|---|---|
| 1. Category | **Utility, Productivity, Communication, or Other** — не выбирайте «Game», приложение не является игрой |
| 2. Email address | `info@mits.kg` |
| 3. Questions | Ответы из раздела 2 ниже |
| 4. Summary | Проверить итоговый рейтинг (раздел 3) |
| 5. Submit | Отправить; рейтинг присваивается автоматически |

Анкета IARC едина для всех магазинов, участвующих в системе, поэтому рейтинги для России, Европы, США и других регионов присваиваются автоматически по одному набору ответов.

## 3. Ожидаемые рейтинги

По набору ответов из раздела 2 IARC присваивает следующие рейтинги.

| Система | Регион | Ожидаемый рейтинг |
|---|---|---|
| **IARC Generic** | Международный | **Everyone / 3+** |
| **Россия (возрастная маркировка)** | Россия | **0+** |
| **ESRB** | США, Канада, Мексика | **Everyone (E)** |
| **PEGI** | Европа | **PEGI 3** |
| **USK** | Германия | **USK 0** |
| **ACB** | Австралия | **G (General)** |
| **ClassInd** | Бразилия | **L (Livre)** |
| **CERO** | Япония | **A (All ages)** |
| **Кыргызстан** | Кыргызстан | Отдельной национальной системы рейтингов в консоль магазина нет: отображается рейтинг IARC Generic — **Everyone / 3+** |
| **Казахстан** | Казахстан | Отображается рейтинг IARC Generic — **Everyone / 3+** |

> Возрастная маркировка для России присваивается автоматически на основе ответов IARC. Ответ «0+» ожидается, поскольку приложение не содержит контента, повышающего категорию: оно не предоставляет контент самостоятельно, не имеет игровых механик, не содержит рекламы разработчика и не позволяет общаться с другими людьми.

Если консоль магазина вернёт иной рейтинг, это повод перепроверить ответы: наиболее вероятная причина — случайно положительный ответ в разделах «Взаимодействие пользователей», «Реклама» или «Обмен данными».

## 4. Раздел «Designed for Families» / «Приложения для детей»

Путь: **App content → Target audience and content**.

### 4.1. Основные вопросы

| Вопрос консоль магазина | Ответ | Пояснение |
|---|---|---|
| Which age groups does your app target? | **Ages 5 and under**, **Ages 6–8**, **Ages 9–12** | Приложение рассчитано на детей примерно 3–10 лет |
| Is your app designed for children? | **Yes** | Интерфейс создан специально для детей: крупные карточки, крупные кнопки, минимум текста |
| Is your app appealing to children? | **Yes** | Яркие превью, эмодзи-коллекции, дружелюбный экран «На сегодня всё» |
| Do you want your app to be reviewed for the Designed for Families programme? | **Yes** | Заявляемся в программу |
| Does your app contain ads? | **No** (собственной рекламы) | См. раздел 2.8 |
| Does your app collect personal and sensitive user data? | **No** | См. Data safety |
| Does your app share personal and sensitive user data with third parties? | **No** | См. Data safety |
| Does your app comply with the Families Policy? | **Yes** | См. раздел 4.2 |
| Does your app appeal to children but is not designed for them? | **No** | Приложение именно designed for children |

### 4.2. Почему приложение соответствует программе Designed for Families

**1. Приложение спроектировано для детей, а не просто «подходит» им.**
Контент отбирается родителем, а ребёнок получает интерфейс, рассчитанный на возраст 3–10 лет: крупные превью, минимум текста, крупные кнопки управления в плеере, отсутствие мелких элементов, в которые сложно попасть пальцем.

**2. Персональные данные не собираются и не передаются.**
Приложение не имеет аккаунтов, регистрации, серверов разработчика, аналитики, трекеров и рекламных SDK. Это подтверждено формой Data safety: все категории — «не собирается».

**3. Реклама разработчика отсутствует.**
Рекламных SDK нет. Единственная возможная реклама — реклама самого видеосервиса в резервном официальном плеере; она не адресована ребёнку целенаправленно, не управляется приложением и не приносит разработчику дохода. При воспроизведении по прямой ссылке интерфейс и реклама видеосервиса не отображаются.

**4. Нет неконтролируемого потока контента.**
В приложении отсутствуют поиск, рекомендации, бесконечная лента, Shorts, комментарии, подписки и каналы. Ребёнок физически не может выйти за пределы отобранного родителем списка.

**5. Внешние ссылки и взрослые функции закрыты родительским PIN-кодом.**
Добавление видео по ссылке, открытие страницы видеосервиса в резервном плеере, смена настроек, лимит времени и удаление данных — всё это доступно только после ввода четырёхзначного PIN-кода родителя. Это и есть parental gate, требуемый для детских приложений.

**6. Данные можно удалить полностью и прозрачно.**
Кнопка «Сбросить всё» в родительском режиме удаляет все локальные данные; удаление приложения удаляет их вместе с приложением. Политика конфиденциальности опубликована по адресу https://mits.kg/privacy-policies/bulak.html и содержит отдельный раздел о детях.

**7. Контент не распространяется приложением.**
Приложение не хранит и не распространяет копии видео: воспроизведение выполняется через официальные механизмы видеосервиса. Это соответствует требованиям магазинов к контенту третьих лиц и правилам использования сервиса.

### 4.3. Дополнительные требования, которые нужно подтвердить в консоль магазина

| Требование | Статус | Как подтверждается |
|---|---|---|
| Политика конфиденциальности опубликована и содержит раздел о детских данных | Готово | `docs/legal/bulak.html` размещается на https://mits.kg/privacy-policies/bulak.html |
| Ссылка на политику указана в листинге | Готово | Раздел 8 файла `listing.ru.md` |

## 5. Частые причины отклонения детских приложений и как их избежать

| Причина отклонения | Риск для «Булака» | Профилактика |
|---|---|---|
| В детском приложении показывается реклама, ориентированная на детей | Низкий: рекламных SDK нет | Не подключать рекламные SDK. Не использовать в описании формулировку «полностью без рекламы» |
| Приложение собирает данные, не раскрыв это | Низкий | Ответы Data safety совпадают с фактическим поведением; в манифесте только `INTERNET` и `WAKE_LOCK` |
| Ребёнок может попасть во внешний интернет без parental gate | Низкий: доступ закрыт PIN | Проверить на реальном устройстве, что все внешние переходы требуют PIN |
| Описание в сторе не соответствует функциям | Средний | Описание сверено со списком функций; нет обещаний блокировки рекламы и скачивания видео |
| Приложение могут принять за официальный клиент видеосервиса | Средний | Брендинг: без чужих логотипов и названий в иконке и названии; в листинге указано, что приложение не связано с видеосервисами |
| Отсутствует ссылка на политику конфиденциальности | Низкий | Ссылка добавлена в оба листинга |
| Скриншоты не соответствуют интерфейсу | Средний | Скриншоты делаются со реальной сборки по плану `docs/store/screenshots-plan.md` |
| В магазинной сборке функции скачивания нет (в личной сборке она включена по умолчанию) | Низкий: функции нет | Не добавлять функцию загрузки; при появлении — пересмотреть правовую модель |

## 6. Чек-лист перед отправкой анкет

- [ ] Категория в IARC выбрана как «Utility, Productivity, Communication, or Other».
- [ ] На все вопросы разделов 2.1–2.9 даны ответы, соответствующие таблицам выше.
- [ ] Полученный рейтинг совпадает с ожидаемым (Everyone / 3+, для РФ — 0+).
- [ ] Возрастные группы выбраны: 5 и младше, 6–8, 9–12.
- [ ] Отмечено «приложение предназначено для детей».
- [ ] Заявлено участие в программе Designed for Families.
- [ ] Форма Data safety заполнена и одобрена.
- [ ] Политика конфиденциальности опубликована и доступна по ссылке из листинга.
- [ ] Родительский PIN проверен на реальном устройстве для всех внешних переходов.
- [ ] В описании и на скриншотах нет логотипов сторонних сервисов и чужих брендов.
