# Документация приложения «Булак» (Bulak)

Добро пожаловать в комплект документации для публикации приложения **Bulak / «Булак»** в Google Play и Apple App Store.

Этот каталог (`docs/`) — единственный источник правды для всего, что связано с юридическими документами, сторами, графикой, сборкой и маркетингом. Здесь нет кода приложения: код живёт в `lib/`, а конфигурация сборки — в `android/` и `ios/`.

---

## Что это за продукт

**Bulak** — это «безопасный YouTube для детей». Взрослый (родитель) сам копирует ссылки на видео с YouTube и сохраняет их в приложении. Ребёнок открывает приложение, листает красивые крупные карточки и смотрит **только те видео, которые отобрал родитель**.

Нет поиска, нет рекомендаций, нет бесконечной ленты, нет Shorts, нет комментариев, нет подписок и каналов. Всё, что хранится в приложении, хранится **только на устройстве**.

> **Важно про товарные знаки.** YouTube — товарный знак Google LLC. Приложение Bulak не связано с Google, не спонсируется и не одобрено компанией Google. В сборке для магазинов приложение не скачивает видео и не хранит их копии: оно воспроизводит контент через официальные механизмы YouTube. В личной сборке можно включить скачивание на устройство — это отдельный режим со своими правовыми рисками, см. [docs/legal/youtube-compliance.md](legal/youtube-compliance.md). Ответственность за то, какие ссылки добавлены в приложение, несёт родитель.

## Как пользоваться этой документацией

- **Если вы готовите релиз** — начните с `docs/publishing/release-checklist.md`, затем пройдите `build-and-release.md` и `signing.md`.
- **Если вы заполняете стор** — откройте `docs/store/google-play/listing.ru.md` и `docs/store/app-store/listing.ru.md`.
- **Если вы публикуете юридические документы** — берите `docs/legal/privacy-policy.html`, он готов к размещению на `https://bulak.tlbk.kg/privacy` без правок.
- **Если вы продвигаете приложение** — `docs/marketing/aso.md` и `docs/marketing/launch-plan.md`.
- **Если вы отвечаете родителям** — `docs/faq.md`.

## Сквозные правила для всех документов

1. **Не обещать лишнего.** Любое утверждение в маркетинговых текстах должно проверяться по списку функций выше.
2. **Про рекламу — только так:** «мы не показываем свою рекламу; в резервном встроенном плеере YouTube может показывать рекламу самого YouTube». Формулировка «полностью без рекламы» запрещена.
3. **Про YouTube — всегда:** YouTube является товарным знаком Google LLC; приложение не связано с Google и не одобрено ею; в магазинной сборке видео не скачиваются и не хранятся.
4. **Про данные — всегда:** персональные данные не собираются; всё хранится локально на устройстве; сеть нужна только для загрузки превью и видеопотока YouTube.
5. **Плейсхолдеры.** Места, требующие личных данных владельца (юридический адрес, ФИО, реквизиты), помечены комментарием `<!-- заполнить перед публикацией -->`. Перед публикацией их нужно заменить — поиск по этому комментарию находит все такие места.
