# Как помочь проекту

Спасибо за интерес к «Булак». Это детское приложение, поэтому требования
к качеству и предсказуемости здесь выше обычного: ошибка в лимите времени
или в родительском замке — это не «мелкий баг», а сломанное обещание
родителю. Ниже — правила, которые помогают этого избежать.

## Прежде чем начать

1. Прочитайте [README.md](README.md) — там описана идея и архитектура.
2. Проверьте [open issues](../../issues) — возможно, задача уже обсуждается.
3. Для крупных изменений сначала откройте issue с описанием предложения.

## Настройка окружения

```bash
git clone <адрес-репозитория> bulak
cd bulak
flutter pub get
flutter analyze
flutter test
```

Требуется Flutter 3.47+ (Dart 3.13+).

## Что мы принимаем с радостью

- Исправления ошибок (особенно: разбор ссылок YouTube, воспроизведение,
  подсчёт экранного времени).
- Новые языки интерфейса: сейчас есть `ru` и `en`, ждём `ky`.
- Улучшения доступности: читаемость, контраст, размеры интерактивных зон,
  поддержка TalkBack и VoiceOver.
- Оптимизацию размера сборки и времени запуска.
- Тесты: любые, которые закрывают существующие пробелы.

## Что требует обсуждения

- Всё, что добавляет сетевые запросы куда-либо, кроме YouTube.
- Любая аналитика, телеметрия и рекламные SDK — по умолчанию нет.
- Скачивание видео и оффлайн-режим: сначала обсуждаем юридическую сторону.
- Изменения схемы хранения: нужна миграция старых данных.

## Правила кода

### Стиль

- Форматирование обязательно: `dart format .`
- Статический анализ должен быть чистым: `flutter analyze` без замечаний.
- Имена, комментарии и сообщения коммитов — на русском языке.
  Тексты интерфейса — только через `AppStrings`.
- Публичные классы и методы сопровождаются комментарием, объясняющим
  **зачем**, а не «что».

### Архитектура

| Слой | Правило |
|---|---|
| `lib/core` | Никаких зависимостей от `data` и `ui`. Только чистые утилиты. |
| `lib/data` | Модели и доступ к данным. Никаких виджетов и `BuildContext`. |
| `lib/state` | `ChangeNotifier`-контроллеры. Никакой вёрстки. |
| `lib/ui` | Только интерфейс. Бизнес-логика живёт в контроллерах. |

### Тексты интерфейса

Каждая строка должна существовать и в русской, и в английской версии.
Добавляя строку, добавьте её сразу в обе ветки `_pick(...)` в
`lib/core/l10n/app_strings.dart`.

### Тесты

- Новая логика в `core`, `data` или `state` — приходит с тестом.
- Новый экран — приходит хотя бы с одним виджетным тестом на ключевой сценарий.
- Тесты не должны ходить в сеть: подменяйте `VideoMetadataSource` заглушкой.

Перед отправкой PR:

```bash
dart format .
flutter analyze
flutter test
```

## Коммиты и pull request

Сообщение коммита — в повелительном наклонении, на русском, с коротким
описанием сути: `исправить подсчёт времени при сворачивании приложения`.

В описании PR укажите:

- что меняется и зачем;
- как проверить (шаги, устройства, версии Android/iOS);
- какие тесты добавлены;
- скриншоты или запись экрана для изменений интерфейса.

## Юридические требования к контрибуциям

Отправляя изменения, вы подтверждаете, что:

- это ваша собственная работа и она не нарушает чужие права;
- вы не добавляете код под лицензией, несовместимой с проприетарной
  лицензией проекта (см. [LICENSE](LICENSE));
- вы не добавляете контент YouTube, ссылки на пиратские копии видео
  и средства обхода технических ограничений сервиса.

## Сообщения об ошибках

Приложите:

- версию приложения (в приложении: «Родителям» → «О приложении»);
- модель устройства и версию ОС;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- ссылку на видео, если ошибка связана с воспроизведением
  (или её идентификатор вида `dQw4w9WgXcQ`).
